# Settings you fill in on the Packs page: "<key> | folder|file|text|longtext|secret | <label>"
resume_file | file | Master resume (a .md or .txt file)
skills | longtext | Skills and experience highlights (only true facts: the writer uses nothing else)
titles | text | Target job titles (comma-separated)
locations | text | Locations, or remote
salary | text | Salary range
exclude | text | Companies to exclude (comma-separated)
sources | longtext | Sources to search: job boards or searches, one per line
site_modes | longtext | Mode per site, one per line: "example.com: auto", "site: prepare" or "site: skip"
email_from | text | Your email address (for email applications)
smtp_host | text | Mail server (SMTP), for example smtp.office365.com
smtp_port | text | Mail server port (587, or 465)
smtp_user | text | Mail server user name
smtp_password | secret | Mail server password or app password (kept in Windows Credential Manager)
